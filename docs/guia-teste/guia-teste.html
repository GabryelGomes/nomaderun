NOMADE RUN — como testar o app

Guia rápido para colegas e professores · TCC de Gabryel Gomes Bahmad Camapum e Mateus Augusto de Faria Brito

O NOMADE RUN é um app de corrida em que cada corrida conquista zonas da cidade para a sua facção. Há duas formas de testar:

FormaPara quemPrecisa de
A. Expo Go (recomendada)Quem só quer usar o app no celularCelular Android ou iPhone e o link/QR do app
B. Código-fonte (zip)Quem vai executar o projeto no próprio computadorPC com Node.js 22+, Expo Go no celular e a chave pública do backend (passo a passo na página 2)

A. Pelo Expo Go mais fácil · 2 minutos

  1. Instale o Expo Go pela Play Store (Android) ou App Store (iPhone).
  2. Abra o link ou QR code do NOMADE RUN enviado pelos autores:
    • Android: escaneie o QR pelo próprio Expo Go (botão Scan QR code).
    • iPhone: escaneie com a câmera do celular e toque em “Abrir no Expo Go”.
  3. Na primeira vez o app demora alguns segundos para baixar. Depois, abre direto pela lista de projetos do Expo Go.
Funciona em qualquer rede (Wi-Fi ou 4G) e não depende de nenhum computador ligado: o app e o servidor estão na nuvem.

Primeiros passos no app

  1. Crie sua conta em “Criar conta” com e-mail e senha (é preciso ter 16 anos ou mais e aceitar a política de privacidade).
  2. Escolha sua facção. Cada facção tem cor e símbolo próprios no mapa.
  3. Permita a localização quando o app pedir: é ela que mede a distância e mostra em que zona você está.
  4. No Mapa, toque em Correr, escolha a missão e toque em Começar. Para terminar, segure o botão de encerrar. O resumo mostra os pontos (RP) e as zonas que você ajudou a conquistar.
  5. Explore as abas Mapa (território de cada facção), Arena (disputa e ranking), Atividades (suas corridas), Clube (crews) e Perfil.
Atenção: regiões e jogadores marcados como “demonstração” são dados fictícios para mostrar o funcionamento. Corridas muito curtas, rápidas demais (ex.: de carro) ou com GPS ruim podem ir para revisão e não pontuar: é o antifraude funcionando.

B. Executando o projeto pelo zip, passo a passo no seu computador

Neste modo o seu computador serve o app para o celular, então ele precisa ficar ligado e com o terminal aberto enquanto você testa. O servidor (contas, corridas, mapa) continua na nuvem: você não precisa instalar banco de dados nem Docker. Os passos abaixo são para Windows; no Linux, macOS ou WSL veja o quadro no fim.

1

Instale o Node.js (só na primeira vez)

  1. Acesse nodejs.org e baixe a versão LTS (22 ou mais nova). Instale clicando em “Next” até o fim, sem mudar nada.
  2. Abra o PowerShell (menu Iniciar → digite “PowerShell”) e confira: 
    node -v
    Deve aparecer algo como v22.x.x ou maior. Se der “não reconhecido”, feche e abra o PowerShell de novo (ou reinicie o PC).
  3. No celular, instale o Expo Go (Play Store ou App Store).
2

Extraia o zip

  1. Clique com o botão direito em nomaderun.zip → Extrair tudo… → escolha, por exemplo, a pasta Documentos.
  2. Você terá a pasta Documentos\nomaderun. Dentro dela, o app fica em nomaderun\apps\mobile.

Evite extrair dentro do OneDrive ou de pastas com acento/espaço no caminho se der erro de instalação.

3

Crie o arquivo .env (endereço do servidor)

O app precisa saber onde está o servidor. No PowerShell, rode os comandos abaixo trocando COLE_A_CHAVE_AQUI pela chave pública que os autores enviaram:

cd $HOME\Documents\nomaderun\apps\mobile
Set-Content .env "EXPO_PUBLIC_SUPABASE_URL=https://rbdxksunpfbaxkelnsob.supabase.co"
Add-Content .env "EXPO_PUBLIC_SUPABASE_ANON_KEY=COLE_A_CHAVE_AQUI"
Get-Content .env

O último comando mostra o arquivo: confira se as duas linhas estão certas, sem espaços antes ou depois do =.

Prefere o Bloco de Notas? Salve em apps\mobile com o nome .env escolhendo “Todos os arquivos” no tipo, senão o Windows salva como .env.txt e o app não encontra.

4

Instale as dependências (só na primeira vez)

Ainda na pasta apps\mobile:

npm install

Leva de 2 a 5 minutos e baixa as bibliotecas do app. Avisos amarelos (warn) são normais; só se preocupe se terminar com ERR!.

Se o PowerShell bloquear com “a execução de scripts foi desabilitada”, rode uma vez Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, confirme com S e tente de novo.

5

Inicie o app

npx expo start --tunnel
  • Se perguntar se pode instalar o @expo/ngrok, digite y e Enter.
  • Se o Firewall do Windows perguntar, clique em Permitir acesso.
  • Em alguns segundos aparece um QR code no terminal. Deixe essa janela aberta.

O --tunnel faz o celular funcionar mesmo em outra rede (4G ou Wi-Fi da faculdade). Se estiver lento e o celular estiver no mesmo Wi-Fi do PC, pode tentar só npx expo start.

6

Abra no celular

  • Android: abra o Expo Go → Scan QR code → aponte para o QR do terminal.
  • iPhone: aponte a câmera para o QR e toque em “Abrir no Expo Go”.

A primeira abertura demora um pouco (o PC está montando o app). Depois, siga os “Primeiros passos no app” da página 1.

7

Para parar e para rodar de novo

  • Parar: no terminal, aperte Ctrl + C.
  • Próximas vezes (não precisa repetir os passos 1 a 4): 
    cd $HOME\Documents\nomaderun\apps\mobile
npx expo start --tunnel
  • Com o terminal aberto, a tecla r recarrega o app no celular.
Linux, macOS ou WSL: os passos são os mesmos, trocando os comandos do passo 3 por: 
cd ~/nomaderun/apps/mobile
cp .env.example .env
nano .env        # preencha a URL e a chave, salve com Ctrl+O e saia com Ctrl+X
Depois npm install e npx expo start --tunnel. (No WSL, o --tunnel é o jeito mais simples de o celular enxergar o PC.)

Problemas comuns

SintomaO que fazer
Tela “Backend não configurado”O .env está faltando, com outro nome (ex.: .env.txt) ou fora de apps\mobile. Corrija, pare com Ctrl + C e rode npx expo start --tunnel --clear.
Login não funciona / “chave inválida”Chave copiada errada ou incompleta no .env. Copie de novo e reinicie com --clear.
QR abre e fica carregando para sempreConfirme que o terminal continua aberto, use --tunnel e confira a internet do PC.
node ou npx “não é reconhecido”Node não instalado ou PowerShell aberto antes da instalação: feche e abra de novo.
Erro de versão do Node no npm installInstale o Node LTS 22+ e rode npm install de novo.
Expo Go pede loginCrie uma conta gratuita em expo.dev e entre com ela no Expo Go.
npm run celular, publicar ou apk dão erro no WindowsSão scripts dos autores para Linux/WSL. Você não precisa deles: use npx expo start --tunnel.

Telas reais · modo demonstração

04/12

- Na primeira abertura, a pessoa cria a conta e escolhe um dos quatro times. A cidade aparece dividida, com a parte de cada time. - Cada time tem cor, forma e mascote. A forma existe para quem é daltônico. - "Não sei escolher" abre um quiz curto que sugere o time. Dá para trocar uma vez por temporada. - Antes de pedir a localização, o app explica para que ela serve. - As telas são capturas reais do app no modo demonstração (dados de exemplo).

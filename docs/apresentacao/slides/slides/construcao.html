Arquitetura em camadas

App: React Native + Expo + TypeScript

Servidor: Supabase, Postgres + PostGIS

Regras do jogo: o mesmo código no app e no servidor

Segurança: RLS em toda tabela, HMAC e antifraude

09/12

- Método em 4 etapas: pesquisa, ERS no modelo da disciplina, protótipo em ciclos curtos, testes. - A ERS: 27 requisitos funcionais, 15 não funcionais, 19 regras de negócio. - Arquitetura: as regras do jogo ficam numa camada sem interface, e o mesmo código roda no app e no servidor. Dá para testar pintura, conquista, Raid e antifraude sem abrir o app. - O servidor é o juiz: cada celular assina os lotes de pontos (HMAC); o servidor confere, roda o antifraude e recalcula a corrida. - Toda tabela tem Row Level Security. A v2 entrou sem quebrar a primeira: as partes novas ficam atrás de chaves que começam desligadas. - React Native com Expo: um único código para iOS, Android e Web.
